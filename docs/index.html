DeepSeek Harness
桌面客户端

基于官方 DeepSeek Harness 构建的桌面端应用，开箱即用，无需配置。支持 Windows 和 macOS 平台，提供便携版和安装版两种选择。

功能特性

🚀

开箱即用

自动检测并连接到现有的 DeepSeek Harness 服务器，无需复杂配置即可开始使用。

💻

跨平台支持

同时支持 Windows 和 macOS 平台，提供一致的用户体验。

📦

多种安装方式

Windows 提供便携版和安装版，macOS 提供便携版，满足不同需求。

🎨

简洁界面

无边框窗口设计，白色主题，提供清爽的视觉体验。

⚡

轻量高效

基于 Electron 构建，启动快速，运行流畅，资源占用低。

🔒

开源安全

完全开源，代码透明，社区维护，安全可靠。
